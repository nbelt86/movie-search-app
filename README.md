# Movie Search

A simple movie search app built with vanilla HTML, CSS, and JavaScript, using the [OMDb API](https://www.omdbapi.com/).

**Live demo:** https://nbelt86.github.io/movie-search-app/

## Features

- Search for movies by title, by clicking the search button or pressing Enter
- Loading indicator while a search is in progress
- Handles empty searches and searches with no results
- Handles network/API errors gracefully
- Click any movie card to view more details (plot, rating) fetched from the API
- Responsive results grid with hover effects

## Built with

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (ES6+): `fetch`, `async`/`await`, template literals, event delegation, `try`/`catch`
- [OMDb API](https://www.omdbapi.com/)

## Running locally

No build tools or dependencies required — it's plain HTML/CSS/JS.

1. Clone the repo
2. Open `index.html` directly in your browser

## Notes

This project was built while learning JavaScript fundamentals from scratch — the HTML/CSS scaffold was set up as a starting point, and all of the JavaScript logic (search, error handling, event listeners, API calls) was written and debugged from there.
